# Set up multi-factor authentication on a new phone

ID: kb-02
Category: access
Last reviewed: 2026-09-18
Note: invented sample data for a course.

Multi-factor authentication (MFA) asks for a six-digit code from the authenticator app as well as your password. On a new phone, install the authenticator app, sign in on your laptop, open Security settings and choose Add device. Scan the QR code with the phone. If you no longer have the old phone, the service desk has to remove the old device first, after checking who you are.
