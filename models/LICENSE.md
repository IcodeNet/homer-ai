# Licence of the ready-made models

The two files in this folder, `odyssey_book1.pt` and `odyssey_book1_gpt.pt`, were trained on Book 1 of the Greek *Odyssey* from the Perseus Digital Library, which is shared under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Each file also stores that text, so the model can rebuild its vocabulary.

To keep things simple and safe, we share both model files under the same licence, **CC BY-SA 4.0**, with the same credit: Homer, *Odyssey*, Greek text edited by A. T. Murray, Perseus Digital Library, Tufts University (details in [data/homer/README.md](../data/homer/README.md)).

The code that trains and loads them is MIT, like the rest of the project ([LICENSE](../LICENSE)).
